# 🎨 Designify

Designify is an AI-powered Interior Design Image Generator built using Flask and Stable Diffusion.

Users can describe any room in natural language, and the AI generates a photorealistic interior design based on the prompt.

---

## Features

- AI-powered image generation
- Modern web interface
- Stable Diffusion integration
- Flask backend
- Responsive design
- Prompt-based room generation

---

## Tech Stack

- Python
- Flask
- Hugging Face Diffusers
- PyTorch
- HTML
- CSS

---

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/designify.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
